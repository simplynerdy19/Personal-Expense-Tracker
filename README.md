# Personal-Expense-Tracker

The Personal Expense Tracker is a command-line Python application designed to help users record, organize, and monitor their daily expenses efficiently. While the original concept focused on basic expense logging, several enhancements were introduced to improve usability and make the tracker more practical for real-world financial management.

The application allows users to add expenses with validated inputs, including dates, categories, amounts, and descriptions. Expenses are automatically maintained in chronological order and saved to a CSV file for persistent storage across sessions. Users can view a well-formatted expense history, set monthly budgets for specific months and years, and track their spending against those budgets. If an expense is added for a month without an existing budget, the tracker intelligently prompts the user to create one. Additional input validation prevents future dates, invalid numerical values, and empty fields, ensuring data integrity. These improvements transform the tracker from a simple record-keeping tool into a more robust personal finance management system that emphasizes accuracy, organization, and ease of use.
